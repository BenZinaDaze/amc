# v0.4.2

## 窗口外观

### macOS 沉浸式标题栏
- 标题栏改为 macOS Overlay 样式：原生白色标题条消失，深色侧栏一路贯通到窗口顶边，与应用整体风格一致。
- 红绿灯（关闭/最小化/全屏）按钮保留系统原生样式，浮于侧栏深蓝背景之上。
- 侧栏顶部新增整宽拖拽区：按住即可拖动窗口，双击可最大化/还原。
- 窗口标题文本不再显示（Mission Control 与程序坞仍正常显示标题）。
- Windows 与 Linux 版本不受影响，仍使用系统原生标题栏。

## 下载说明
DMG 未签名。复制到 `/Applications` 后若无法打开，执行：

```sh
xattr -cr /Applications/AMC.app
```
