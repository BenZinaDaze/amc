# v0.7.0

## 新增 Agent：ZCode

AMC 接入第四家 Agent——ZCode（桌面应用）。已安装 ZCode 时自动检测并纳入各功能；未安装不影响其他 Agent。

### 用量统计（Agents 页）
- 新增 ZCode 详情页：读取其本机数据库（`~/.zcode/cli/db/db.sqlite`）的逐请求记录，按模型归档统计请求数、Token 与费用，与其余三家同口径。
- ZCode 数据库的 `input_tokens` 是含缓存命中的 prompt 合计，AMC 自动换算为净输入后再归档，缓存命中率与费用因此准确（换算依据见下「问题修复」）。
- 模型名统一按小写归一后匹配计价表（如 `GLM-5.3` → `glm-5.3`），GLM 系列可正常计价。

### MCP 管理
- MCP 服务可勾选同步到 ZCode：写入 `~/.zcode/cli/config.json` 的嵌套键 `mcp.servers`，同文件中的 hooks / plugins 状态原样保留；写入前照常生成变更预览。
- 不依赖 ZCode 对 `~/.agents/mcp.json` 的兼容回退——该回退在用户于 ZCode 设置界面手加任意服务后会整体失效，直接写 `mcp.servers` 不受影响。

### Skills 分发
- 新增 `~/.zcode/skills` 投影目标：目录即开关，与 Claude Code 同模式；安装 / 更新 / 移除均纳入现有预览流程。
- ZCode 会自动发现 `~/.agents/skills`（OMP 与 Codex 共用目录）中的技能：对 ZCode 停用某技能时，若共享目录副本仍在，AMC 会同时在其 `config.json` 写入 `skillOverrides` 禁用项（按 SKILL.md 绝对路径）保持隔离，避免「已停用却仍被 ZCode 加载」。

### 安装检测
- Agents 页新增 ZCode 卡片：按数据目录探测安装状态，版本读取其数据库中最近会话的客户端版本。
- ZCode 是桌面应用、更新在应用内完成，AMC 不提供代查代更（卡片有说明）。

## 问题修复

### ZCode 用量口径（发布前修正）
- ZCode 数据库的 `input_tokens` 存的是含缓存读的 prompt 合计（对账实测：净输入 1215 + 缓存读 270592 → 存 271807），首个适配实现未做换算即入档，会导致缓存命中率被低估约一半、总 Token 与费用虚高。本版本在适配器内换算为净输入，并在升级时自动清理旧口径的 ZCode 归档行（读取时立即按新口径重扫重建，其他 Agent 的归档不受影响）。

## 内部
- `mcp_servers` / `skills` 表新增 `zcode` 列（老库自动 ALTER 迁移）；用量归档 schema 升至 v2。后端测试增至 135 个。
