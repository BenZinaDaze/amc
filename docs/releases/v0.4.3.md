# v0.4.3

## 订阅与配额

### Google Antigravity 订阅
- 新增 Antigravity 卡片：点"通过 Google 登录"走浏览器 OAuth 授权（PKCE + 本地回调，无需安装 Antigravity 或 agy CLI），授权后 refresh token 只保存在本机、不出后端，卡片以账号邮箱标识。
- 额度展示两个共享池 × 两个窗口共四条计量条：Gemini 模型与 Claude/GPT 模型各自的 5 小时滚动窗口与每周窗口，含剩余比例与重置倒计时；套餐层级（Pro / Ultra）来自 loadCodeAssist。
- 查询走 Google Cloud Code 内部接口（非官方文档接口，格式可能随版本变化）；后端按 User-Agent 校验 client 身份，请求携带 IDE 风格 UA。
- 支持多账号：一张卡片一个授权，并行刷新。

### DeepSeek 余额卡片
- 新增 DeepSeek 卡片：粘贴 API Key 读取官方 `GET /user/balance`，按币种展示余额（¥ / $），赠金与充值进明细行，`is_available` 显示可用状态；Key 无效时卡片直接提示。
- 预付费余额不再套计量条：余额渲染为标签 + 金额单行（无百分比、无进度条、无重置倒计时）；Sub2API 钱包模式同步改为该形态。
