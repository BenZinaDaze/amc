# v0.5.2

## Agents

### 运行时更新检测与一键更新
- 「已接入 Agent」卡片在检测到运行时并读到版本后，自动查询远端最新版本：OMP 走 GitHub Releases（`can1357/oh-my-pi`），Claude Code 与 Codex CLI 走 npm registry 的 latest 端点；查询失败静默忽略，不打扰使用。
- 有新版时卡片显示「更新到 x.y.z」标签，点击即调用各 CLI 自带的更新命令（`omp update` / `claude update` / `codex update`），全程不跳转外部页面。
- 更新复用与检测同一套候选目录搜索与 Finder 安全启动器（bun/npm shim 可正常执行）；命令的非零退出优先把 CLI 自己的 stderr 显示到错误提示条，比如改由包管理器管理时会原话转达。
- 更新成功后自动重测本地版本（OMP 重载 state，Claude/Codex 走状态接口），已到最新时更新标签自动消失。
- 检出状态文案由「已检测到 / 未检测到」改为「已安装 / 未安装」，三个用量页的版本 pill 同步。
