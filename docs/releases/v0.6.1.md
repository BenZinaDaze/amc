# v0.6.1

## 订阅与配额

### 单卡刷新
- 订阅卡片右键菜单新增「刷新」：只重新查询当前这张卡片的套餐与配额，不必整批刷新；查询期间该卡显示加载骨架，其余卡片保持原样。
- 查询失败时错误直接显示在卡片内（与整批刷新一致），不打断其他卡片的展示。

## 稳定性与安全

### 凭据与写入安全
- 订阅凭据文件改为原子写入：写入中途崩溃最多留下一个暂存文件，正式文件始终完整；文件意外损坏时会明确报错并保留原文件，不再被当作空列表悄悄覆盖，杜绝凭据丢失。
- 技能 / MCP 应用变更时，若配置文件写入或数据库提交失败，相关文件会自动还原到应用前的状态，不再残留「目录已更新但记录未保存」的中间态。
- GLM 配额接口报错时能看到接口返回的具体原因（如 Key 失效），不再只有一行状态码。

### 体验与性能
- 本地 Git 仓库在仓库页正确显示为「本地 Git 仓库」卡片：文件夹图标、本地路径与专属的移除提示（原始路径不会被删除）。
- Skills 列表刷新提速：仓库提交未变化时跳过整仓重读，多技能场景下刷新不再卡顿。
- 个别 CLI 在版本探测时卡住不再拖住整个界面（探测 5 秒超时）。
- 生产包启用内容安全策略（CSP），并扩充变更预览中敏感字段的脱敏名单。

## 下载说明

```sh
xattr -cr /Applications/AMC.app
```
