# v0.4.1

## 统计

### 失败请求不再计入统计
- OMP 的失败请求（`error`/用户中断 `aborted`）本就不产生 token 与费用（记 0），此前却被计入请求数：现从扫描起剔除，模型明细不再出现纯失败行撑起的请求数。
- 流中断但已产生 token 的失败响应（部分输出已计费）仍正常统计。
- 用量归档新增写入守卫：不携带 usage 的记录永不入库；已入库的历史 0 用量行在本次升级后首次启动时自动清理（一次性迁移）。
- Claude Code 与 Codex 的失败请求本就不产生可统计的 usage，不受影响。

## 计价

### 新增模型定价
- `gemini-3.7-flash`、`gemini-3.8-flash`：input $0.75 / output $3.75 / 缓存读 $0.075（官方介绍价，至 2026-12-31）。已装版本刷新用量时自动获取。
