## 新增功能

### GLM 订阅用量按重置周期统计
- 订阅卡片的 Token 用量、模型请求与分模型用量改为按本周点数重置周期（上次周重置 → 现在）统计，标签注明「（本周）」，与「点数用量（1 周）」进度条口径一致；配额接口未返回周期数据时回退滚动 24 小时。
- 修正滚动窗口下总量与分模型互相矛盾的问题：接口的 `totalTokensUsage` 按小时精确裁剪窗口，`modelSummaryList` 按自然日整日聚合，滚动 24 小时窗口下两者不可比；周期窗口下总量与分模型之和完全相等。

## 内部重构
- `subscription.rs`（约 1180 行）拆分为 `subscription/` 目录：`mod.rs`（共享类型、供应商目录与注册表）、`store.rs`(存储、0600 权限、旧格式迁移、增删改查)、`glm.rs`（GLM 供应商自包含）；新增供应商只需目录加一行、新建供应商模块并注册一处。
- 发布流程加固（仅 CI 与钩子）：tag 推送按远端 ref 名拦截；发布说明需以提交 oid 逐条确认自上个 tag 以来的每个 feat 提交。
