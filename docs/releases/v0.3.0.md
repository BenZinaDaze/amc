## 新增功能

### Codex CLI 用量统计
- Agents 页新增 Codex CLI 检测卡片与独立用量页，头部徽标展示 `codex --version` 版本；Agents 汇总统计自动包含 Codex。
- 解析 `~/.codex/sessions`（支持 `CODEX_HOME`）下的 rollout 会话转录，按 `token_count` 事件的每轮增量（`last_token_usage`）累计；旧格式仅含累计值时按差值回退。
- 跟随会话内 `/model` 切换分别按模型计价；无模型上下文的转录归入 `openai / unknown` 且不计价。
- fork 会话不重复计费：
  - `ForkPersistence::Copied` 复制进子文件的父前缀按事件身份（`turn_id` + 内容）跨文件去重，父线程 fork 后继续产生的独立轮次照常计入；
  - `Referenced` fork 继承的父基线不计入子会话（优先取本轮 `last_token_usage`，仅有累计值时差值回退）；
  - 限流更新重播的未变化快照（`update_rate_limits`）不重复计费；同一轮内多个 API 响应各自计入。
- 父文件超出统计范围（mtime 早于起始时间）时，子文件中的继承前缀仍可正确识别，不会复活父会话的轮次。

### 内部重构
- 各 Agent 适配器拆分至 `src-tauri/src/usage/`（`mod.rs` + `agents/omp.rs`、`agents/claude.rs`、`agents/codex.rs`，每源一文件）；新增数据源只需实现适配器 trait 并注册一处。
