## 新增功能

### Agent 用量统计本机归档
- 用量统计不再直接聚合各 Agent 的实时数据，而是先把每条原始请求记录归档进 AMC 自有数据库（`usage.sqlite3`，按来源与记录标识去重），再从归档按时间范围聚合计价。Agent 清理自身会话记录（Claude Code/Codex 转录、OMP stats.db）后，已归档的统计仍然可查，不再随源数据丢失。
- 成本在查询时按当前计价目录重算：归档只存原始 token 分桶，计价目录更新会自动重定价历史记录；路由模型（如 Claude Code 走 GLM）的供应商归属也在查询时解析，目录补充条目后历史记录可正确计价。
