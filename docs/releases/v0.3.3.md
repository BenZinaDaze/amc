## 新增功能

### MCP 集中存储与按 Agent 分发
- MCP 管理改为以 AMC 自有 SQLite（`amc.sqlite3`）为唯一事实来源：保存中立的服务定义与每个 Agent（OMP / Claude Code / Codex）的启用开关，各 Agent 的用户级配置文件只是投影。
- 每个适配器只读写自己的配置：OMP `~/.omp/agent/mcp.json`（profile/env 感知）、Claude Code `~/.claude.json`（支持 `CLAUDE_CONFIG_DIR`）、Codex `~/.codex/config.toml`（支持 `CODEX_HOME`，经 `toml_edit` 保格式编辑）；保存与开关沿用 plan/apply 预览流程，原子替换。

### Skills 用户级投影分发
- 中央技能库（数据库记录 + 数据目录副本）投影到 `~/.agents/skills`（OMP 与 Codex 共用）与 `~/.claude/skills`；OMP 与 Codex 通过各自配置文件独立开关，两者都关闭时才删除目录。
- 投影所有权按启用状态哈希校验：用户自放的副本（即使内容相同）不会被触碰；旧的工作区安装启动时一次性迁移（哈希校验、原子、可重试）。配置写入先脱敏预览，失败与目录写入共用同一回滚路径。

### 按安装检测门控 Agent 开关
- MCP/Skills 的 Agent 开关只对检测到已安装的 Agent 可用；未安装时保持可见（置灰），已启用的开关随时可以关闭。
- MCP 卡片新增脱敏详情行：URL 剥离查询串/片段/userinfo，stdio 只显示命令名与参数个数；统一 MCP/Skills 卡片骨架、开关尺寸与「移除」文案。

## 界面优化

### 自定义日期范围选择组件
- 用量统计的自定义时间范围不再使用浏览器原生日期输入框：开始/结束日期改为与整体 UI 风格一致的自绘单月日历弹层（accent 高亮当前值与今天、`‹ ›` 翻月），在字段下方弹出、视口不足时自动上翻，并随月份行数变化重新定位。
- 键盘完整可用：方向键/Home/End 移动焦点日，PageUp/PageDown 翻月（加 Alt 翻年），Escape 先关日历再关弹层，点击外部关闭；保留原有的范围校验（开始不得晚于结束）与应用禁用逻辑。
