## 界面优化

### 自定义日期范围选择组件
- 用量统计的自定义时间范围不再使用浏览器原生日期输入框：开始/结束日期改为与整体 UI 风格一致的自绘单月日历弹层（accent 高亮当前值与今天、`‹ ›` 翻月），在字段下方弹出、视口不足时自动上翻，并随月份行数变化重新定位。
- 键盘完整可用：方向键/Home/End 移动焦点日，PageUp/PageDown 翻月（加 Alt 翻年），Escape 先关日历再关弹层，点击外部关闭；保留原有的范围校验（开始不得晚于结束）与应用禁用逻辑。
