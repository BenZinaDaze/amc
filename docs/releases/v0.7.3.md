# v0.7.3

## zcode 远程设备用量同步

zcode 连接远程设备（SSH）时在远程机上运行独立的 host，用量数据只存在远程机的 `~/.zcode/cli/db/db.sqlite`，本机不留任何副本——AMC 此前的统计因此看不到这部分。本版本补上这块拼图：

### 设置页新增「远程设备」tab
- 自动探测 zcode 配置过的远程 SSH 设备（读取 `~/.zcode/v2/setting.json`），列出安装状态、host 版本与上次在线时间；在 zcode 里新连设备后点「刷新」即可出现。
- 每台设备可编辑主机/端口/用户名并录入 SSH 密码：探测值只作默认（应对设备换网络后地址漂移），以你在 AMC 保存的为准；密码以 0600 权限存储在本机，界面只显示「已保存」，不回显任何片段。
- 设备卡片默认折叠，点击头部展开；折叠态保留「用户@主机 · 上次同步」摘要。

### 手动同步
- 「立即同步」经 SSH 拉取远程用量数据库快照（db + WAL + SHM），归档入库并自动并入 ZCode 用量统计；重复同步只取增量，幂等无重复计数。
- 与本地统计同一套语义：净输入换算（扣除缓存读写）、模型名归一、按计价表计费，远程数据不再缺席。
- 首次连接固定主机密钥指纹（TOFU），此后指纹变化会被拒绝，防止中间人；设备离线、认证失败、远程未安装 zcode 均给出明确提示。
- 已在 zcode 里移除的设备保留凭据并可「两击确认移除」：清理 AMC 侧的凭据、指纹与快照；已归档的用量统计保留。

### 其他
- 全量 rustfmt 格式化（随本版引入，后续功能 diff 不再混入格式噪音）。
