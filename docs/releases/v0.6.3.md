# v0.6.3

## 问题修复

### 订阅卡片
- 修复 GLM Coding Plan 卡片 Token 用量自相矛盾的问题：不再显示按模型拆分的 Token 明细。该明细在服务端按「天」粒度聚合，周周期从周中某时刻开始时，会把上一周期当日 0 点到重置点之间的用量整段计入，导致明细之和可达「Token 用量（本周）」总数的两倍以上。
- 「Token 用量（本周）」「模型请求（本周）」口径不变，仍为本周重置周期内的累计用量，与重置进度条覆盖同一周期；重置后自动从零重新累计。
