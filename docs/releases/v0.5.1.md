# v0.5.1

## 订阅与配额

### 新增 Cursor 订阅
- 添加套餐时选择 Cursor，授权走浏览器完成：本地生成 PKCE 挑战并打开 `cursor.com/loginDeepControl`，后端轮询登录结果自动换回凭据——无需安装 Cursor CLI、无需内嵌 WebView、无需手动粘贴 Cookie。
- 卡片展示 Cursor Models / Other Models / Total 三条使用比例与账期重置倒计时，附套餐层级（如 Pro）与账号邮箱；接口无金额字段，故不展示美元数值。
- 网页登录 token 约两个月有效（Cursor 不提供刷新端点），过期后卡片提示，删除该套餐重新登录即可；凭据只保存在本机，界面仅见掩码提示。
- 额度接口为 Cursor 内部接口（非官方，无兼容承诺），全部字段防御式解析：`planUsage` 缺失或形状变化时返回空额度行，不臆造数值。
