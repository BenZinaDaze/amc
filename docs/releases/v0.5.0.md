# v0.5.0

## 界面组件

### 下拉与复选框全面自绘
- 「套餐类型」「平台」下拉不再弹出系统原生菜单：自定义浮层与应用视觉统一（白底圆角、紫色调选中态与对勾），支持方向键/Home/End/Enter/Escape 键盘操作，菜单挂载于 body 不受弹窗裁剪。
- 复选框改为品牌紫色自绘样式（MCP 弹窗的 Agent 勾选与 JSON 编辑开关）。

### Token 用量趋势改为柱状图
- 按小时一柱（24h 与 ≤48h 自定义区间），空闲时段如实留空、不再被压缩成连续图形；1h 区间为 5 分钟粒度，更长区间按天/周。
- 悬停或键盘聚焦柱区可查看该时间段的 Token 数与请求数。

### 版本更新检测
- 启动后自动查询 GitHub 最新 release；有新版本时右下角版本区出现「有新版 x.y.z」提示，点击直达发布页。查询失败静默忽略，不打扰使用。

## 其他改进
- 侧边栏 Agents 分组支持折叠/展开（箭头按钮或键盘）。
- 错误/成功提示条在切换页面后自动收起，不再跨页残留。
- 前端拆分为 pages / apps / components 三层架构，App.tsx 只保留壳与全局状态（内部重构，行为不变）。

## 下载说明
DMG 未签名。复制到 `/Applications` 后若无法打开，执行：

```sh
xattr -cr /Applications/AMC.app
```
