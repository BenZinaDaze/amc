# v0.4.0

## 计价与统计

### 定价只按模型
- 计价目录 `model-pricing.json`（格式 v2）移除每条目的 `providers` 字段：费用一律按模型名计算，不再校验 provider 归属——中转（relay）来源的模型同样正常计价，不再落入未计价。
- 用量归档 `usage_records` schema 移除 `provider` 列：模型明细只按模型聚合，界面不再显示提供方。

### Token 单位新增 B 档
- Token 数量 ≥ 10 亿时显示 `x.xxB`（此前只有 K/M，超大数值会显示成 `1234.57M`）。

### 模型明细排序
- 模型明细表（总览 Agents 页与各 Agent 页）支持点击表头排序：请求数 / 总 Token / 缓存命中率 / 费用，点一下降序、再点一下升序，切换列从降序开始；未计价费用恒排最后。

## 界面

### 屏蔽 WebView 右键菜单
- 应用内右键不再弹出与程序无关的系统菜单；输入框与可编辑区域保留系统菜单，粘贴不受影响。

## 清理

- 移除旧版本兼容代码：工作区安装（installations 表）迁移、mcp_servers/skills 旧 schema 迁移、订阅单套餐旧格式迁移、OMP 旧版 skills 兼容目录探测。

## 下载说明
DMG 未签名。复制到 `/Applications` 后若无法打开，执行：

```sh
xattr -cr /Applications/AMC.app
```
