## 新增功能

### Agents 用量统计
- Agents 页汇总所有 Agent 的请求数、Token 总量与已计价费用小计，并按「提供方 / 模型」分列明细（请求数、Token、缓存命中率、估算费用）。
- 时间过滤与 OMP 一致：近 1 小时 / 24 小时 / 7 天 / 14 天 / 30 天 / 90 天 / 全部，或自定义起止日期。
- 点击「刷新状态」同步最新用量数据。

### 远程模型定价目录
- 新增仓库根目录自有定价文件 `model-pricing.json`（USD / 1M tokens），取代内置的 915KB LiteLLM 定价包，安装包显著减小。
- Agents 页「刷新状态」时自动从远程仓库根目录拉取最新定价并原子替换本地缓存：调价只需改这一个文件推送到 GitHub，无需重新安装或发版。
- 补充 `glm-5.3`、`glm-5.3-flash`、`gpt-6.1-sol`、`jev-latest` 等模型定价。

### 订阅与配额
- 概览页新增「订阅与配额」卡片，通过 Z.ai / 智谱 BigModel 官方监控接口展示 GLM Coding Plan 的配额窗口（5 小时 / 每周）、MCP 用量与近 24 小时模型用量，替代原「需要关注」区块。
- 支持同一套餐添加多个实例（如多个 GLM Key），套餐名称可自定义，卡片一眼可辨。
- 卡片支持右键「编辑 / 删除」，添加弹窗内的原「清除 / 移除」入口随之取消。
- 凭据以 `0600` 权限保存在本机 `subscriptions.json`，不离开本机进程。

### 界面
- 全新应用图标，应用内品牌标识同步统一。
- 更新界面 Web 字体与 README 界面截图。

## 问题修复
- 修复添加套餐弹窗中平台下拉框与 Key 输入框高度、字号、内边距不一致的问题，弹窗控件样式现已统一。
- 修复部分模型（如 `glm-5.3`、`gpt-6.1-sol`）缺少定价导致费用无法估算、请求显示为未计价的问题。
