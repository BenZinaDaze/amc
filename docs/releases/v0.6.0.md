# v0.6.0

## 自动更新

### 应用内检查与一键更新
- 新增应用内自动更新：启动后自动检查新版本，有新版时侧栏出现「有新版 x.y.z」，点开更新弹窗即可查看版本迁移与更新说明；下载带进度条，完成后一键重启生效，无需再到 Releases 页手动下载 DMG。
- 「设置 → 关于」提供「检查更新」按钮，可随时手动检查；未联网或检查失败只作提示，不打断使用。
- 更新包经 Tauri minisign 私钥签名，安装前以内置公钥校验签名，校验不通过不安装。
- 发布管线同步升级：CI 在产出 DMG 的同时生成签名的更新器归档与 `latest.json`（最后单独上传，确保更新端点不会指向半成品 Release）；自本版本起，后续升级都可以在应用内完成。

## 设置页

### 配置文件位置速览
- 新增「设置」页：集中展示 OMP / Claude Code / Codex CLI 的用户级配置文件位置（含各自环境变量覆盖后的实际路径）与工作区目录；「关于」标签页展示应用版本并提供手动检查更新。

## 变更预览

### git 风格统一 diff
- 变更预览改为 git 风格统一 diff：逐文件折叠展示，新增行与删除行按行内高亮，改动一目了然；「先预览确认、后写入」的流程保持不变。

## 下载说明
DMG 未做 Apple 公证。复制到 `/Applications` 后若无法打开，执行：

```sh
xattr -cr /Applications/AMC.app
```
