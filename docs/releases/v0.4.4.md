# v0.4.4

## 订阅与配额

### 卡片逐张刷新
- 订阅卡片不再等全部查询完成才出现：进入概览页先按存储顺序展示占位卡片（图标 + 名称 + "正在查询配额"），每张查完立即填充配额条与用量数据，无需等待最慢的供应商。
- 手动刷新时旧数据原地保留、完成一张更新一张，不再整屏等待或闪烁。
- 增删套餐后卡片列表立即对齐（对齐成员与顺序），已有数据保留等待更新；快速连续刷新时按请求编号丢弃过期事件，不会出现旧数据覆盖新数据。
