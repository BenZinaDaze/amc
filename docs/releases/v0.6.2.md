# v0.6.2

## 更新体验

### 应用内更新弹窗
- 更新说明按 Markdown 排版展示：标题、列表与代码块不再以原始符号呈现，与发布文档的阅读体验一致。

### Agent 更新通知
- 在 Agents 页更新 OMP / Claude Code / Codex 后，通知改为一句中文结论，如「OMP 已从 18.8.7 更新到 18.10.0」；版本未变时提示已是最新版本。
- 通知由更新前后实测的版本号生成，不再展示 CLI 的多行英文日志；仅当更新后探测不到版本时才回退展示原始输出，并保留换行、剔除颜色控制符。

## 下载说明
DMG 未做 Apple 公证。复制到 `/Applications` 后若无法打开，执行：

```sh
xattr -cr /Applications/AMC.app
```
