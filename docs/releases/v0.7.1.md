# v0.7.1

## 界面修正

### Agent 品牌图标对齐官方设计
- 四家 Agent 的品牌标记统一为官方矢量设计：ZCode 换用 Z.ai 官方标记（与 ZCode 应用图标同形的三段断开 Z）；OMP 换用 omp.sh 官网 favicon 的 π 形几何，并按官方配色以粉-紫-青对角渐变填充（取代原先的橙色），Agents 页卡片底板同步为官方深紫黑。
- 修正四个标记视觉大小不一的问题：OMP 标记原先只占图标画布的约六成，现放大至与 Claude / Codex 相同的全幅占比，在卡片、侧边栏与开关中均一致。
- 侧边栏 Agents 分组的四个子项与 Agents 页的四张运行时卡片改用同一套品牌标记（原为线框示意图）：导航中选中哪个页面哪个标记亮品牌色；卡片中跟随安装状态——已安装亮品牌色、未安装灰色。
